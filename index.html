Autonomous Underwater Vehicle

Exploring below the surface, on its own.

A small, open project to design and build an underwater robot that can navigate, sense its surroundings, and complete missions without a tether.

See progress View on GitHub

About the project

An AUV is a robot submarine that runs a mission by itself: no pilot, no cable. This project covers the full stack, from the pressure hull and thrusters to the electronics, sensors, and the software that decides where to go next.

The goal is a vehicle that can dive, hold depth and heading, follow a planned route, and surface with the data it collected.

Key features

🧭

Autonomous navigation

Follows waypoints using an IMU, depth sensor, and dead reckoning.

⚙️

Vectored thrusters

Multiple thrusters for control over depth, heading, and pitch.

📷

Onboard sensing

Camera and environmental sensors log data throughout each dive.

🔋

Untethered power

Battery pack sized for missions of useful length.
